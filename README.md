## 特色

- 🗂 **620 題題庫**:病嬌 250 題 + 傲嬌 250 題 + 家族控情境題 120 題(六大屬性均衡分布)
- 🎲 **每回隨機出卷**:每次測驗從題庫隨機抽出 15 題,並自動避開你最近玩過的題目(約 5 場內不重複)
- 📊 **雜誌風結果頁**:指數測驗有大字百分比 + 刻度尺 + 判定膠囊;家族控有屬性大字 + 六屬性得分排行榜
- 📰 **日系清新雜誌風**:米白紙感、襯線大標、髮絲線版式,三主題色(粉/橘/抹茶綠)
- 📱 響應式設計,手機也能順暢遊玩
