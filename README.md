# LOVE LAB|戀愛屬性鑑定特輯 💗

病嬌指數 × 傲嬌指數——日系雜誌風的娛樂向心理測驗網站。

**▶ 線上遊玩:[https://clz0731.github.io/love-lab-quiz/](https://clz0731.github.io/love-lab-quiz/)**

## 特色

- 🗂 **500 題題庫**:病嬌 250 題 + 傲嬌 250 題,全部戲謔搞笑、無危險內容
- 🎲 **每回隨機出卷**:每次測驗從題庫隨機抽出 15 題,並自動避開你最近玩過的題目(約 5 場內不重複)
- 📊 **6 級鑑定**:從「純情白紙級 🕊」到「病嬌殿堂級 👑」、「直球天使級 😇」到「傲嬌殿堂級 👑」,附雜誌專欄口吻的幽默診斷文
- 📰 **日系清新雜誌風**:米白紙感、襯線大標、髮絲線版式
- 📱 響應式設計,手機也能順暢遊玩

## 技術

純靜態網頁:**零框架、零外部依賴、離線可玩**。

| 檔案 | 說明 |
|---|---|
| `index.html` | 單頁式版型(封面 / 測驗 / 結果) |
| `styles.css` | 日系雜誌風設計系統 |
| `script.js` | 隨機抽題、避題機制、計分與動畫 |
| `questions.js` | 500 題題庫資料 |

## 本機遊玩

直接雙擊 `index.html` 即可,不需要伺服器或安裝任何東西。
